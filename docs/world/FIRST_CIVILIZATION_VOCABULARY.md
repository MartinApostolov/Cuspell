# First Civilization Vocabulary

_Status: first broad historical/worldbuilding vocabulary pass_

This file lists the first deliberately seeded Old Name vocabulary for concepts a functioning society is likely to need repeatedly. English glosses are editorial labels only. The **actual Cuspell vocabulary is the exact quoted Old Name** in the second column.

The names are intentionally descriptive and sometimes imperfect. Once a description fossilizes as an Old Name, the world concept—not the literal wording—determines membership. Later Old Names may reuse earlier Old Names recursively.

## Foundational roots added for this pass

The pass added only productive descriptive/semantic roots rather than English object nouns:

| Root | Role |
| --- | --- |
| Big | contextual size/extent-above-standard Property |
| Small | contextual size/extent-below-standard Property |
| Hard | contextual resistance-to-deformation Property |
| Sharp | contextual edge/point Property |
| Grow | contextual growth Process |
| Sleep | persistent sleep-state Property |
| Sign | semantic/information-bearing Kind |
| Information | informational Kind/domain |
| Rule | rule/instruction Kind |
| Region | spatial Region Kind |
| Path | ordered route/path Kind |
| Write | produce a persistent/written Sign Process |
| Read | interpret a Sign Process |

Big/Small/Hard/Sharp/Grow/Sleep remain contextual in ordinary language and cannot silently become objective magical thresholds. Their use inside a historical Old Name contributes spelling/mana history; it does not re-run the original descriptive phrase each time the Old Name is used.

## Important interpretation rules

- Do **not** use the English gloss as Cuspell. `Ship` is not a root or Old Name; `«Big«MoveInLiquidThing»»` is the registered Old Name in this pass.
- Nested names carry the complete frozen mana cost of the earlier Old Name. They are not flattened to one mana.
- These world concepts currently carry `classifier_status: world-ontology-required`. The vocabulary can refer to the concepts, but a later world package still has to provide objective recognition/generation rules where magic needs them.
- Existing legacy direct noun roots such as Water, Human, Hand, and Cat remain temporarily for compatibility. This pass does not silently migrate them.
- The vocabulary is a starting historical layer, not a claim that every culture must coin the same terms.
