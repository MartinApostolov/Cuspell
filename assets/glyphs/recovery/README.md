# Cuspell glyph recovery (October 2026)

This directory is a **reconstruction**, not the lost original v0.19 glyph set. It preserves the surviving v0.13-based outlines plus approximate reconstructions through G150, with explicit provenance. Glyph identity remains separate from meaning; no semantics have been assigned.

- **G001–G080 and G087–G090:** exact v0.13 SVG data (84).
- **G081–G086 and G091–G110:** visually approximated from later revision notes (26).
- **G111–G130:** outlines traced from surviving v0.16 R3 and v0.17 R1 screenshots (20). Tracing does not recover original Bézier control points or gesture order.
- **G131–G132:** traced from an unlabeled screenshot, tentatively identified and requiring confirmation (2).
- **G133–G140:** from v0.18 descriptions (8, including previously accepted G137/G138 whose geometry is now an approximation).
- **G141–G150:** from v0.19 descriptions (10 unreviewed candidates).

The active inventory is 150 glyphs, one monospaced 600-unit cell per glyph, 1000-unit em, and exact horizontal mirror pairing for newly recreated pairs. The reviewed v0.13 original files remain authoritative over descriptions when available.

**Important**: do not merge reconstructed candidates into approved glyph inventory without user review. The materials here are a recovery source, not the same as restoring the original v0.19 files. Keep the older baseline and screenshot source evidence whenever it is available.

Source/builder files will be added on this recovery branch.
