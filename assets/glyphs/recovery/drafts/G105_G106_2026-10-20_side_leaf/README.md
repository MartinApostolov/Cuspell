# G105 / G106 — side-leaf sprig (unapproved)

The user noticed that our earlier leaf-on-top version of G105/G106
resembled the original v0.14 G091/G092, which are a closed upper loop
with a lower curved tail.

**Proposed design:** move the leaf to the **side of a continuous curving
vertical stem**, rather than forming its upper endpoint. Each glyph has
one long gently S-shaped stem and one closed leaf contour, mirrored.
This deliberately changes the overall silhouette from G091/G092
while retaining the user's intended "leaf on a curvy stick".

The original R4 top-leaf draft is in `prior_rejected/` for history.
These side-leaf SVGs are **not approved or canonical**. Wait for review.

G107/G108 are independently approved and stored canonically.
