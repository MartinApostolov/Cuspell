# Idylwild → Cuspell style proof 01

**Status: UNREVIEWED SAMPLE ONLY.** This branch includes 16 editable derivative SVGs under svgs/ (8 Runic, 8 Alchemical), plus two visual comparison sheets. The sample does **not** alter G001–G150, the canonical source registry, meanings, or the original Idylwild archives.

Open [index.html](index.html) in a browser for the whole comparison, or view [runic_comparison.svg](runic_comparison.svg) / [alchemical_comparison.svg](alchemical_comparison.svg) directly. The comparisons embed real source sprite-sheet pixels and genuine canonical Cuspell vectors; they remain viewable as standalone SVGs.

## Proposed style

- 600 × 1000 em; stroke width approximately 66 (round caps and joins) with optical rather than mathematical normalization.
- Smooth organic centerlines; retain the original topology, essential gaps, dots, junctions, and multiple stroke features.
- Preserve strong asymmetry and unique signatures where possible, even when an imported icon uses conventional geometric motifs.
- Test legibility at small sizes; complex alchemical glyphs may need additional simplified variants.
- This is an initial hand-redraw, not a faithful auto-trace. All 16 are prototypes pending user KEEP / MODIFY / REJECT.
