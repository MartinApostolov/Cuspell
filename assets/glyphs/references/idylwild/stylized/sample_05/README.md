# Cuspell / Idylwild — stylization batch 05

**Candidate artwork only.** 8 more Runic + 8 more Alchemical sources adapted into independently editable SVGs on a 600×1000 em canvas using 66-unit rounded centerlines. The user approved the overall style of batches 01–04; this batch is awaiting review.

Use [index.html](index.html) to compare, or zoom directly into [Runic comparison](runic_comparison.svg) and [Alchemical comparison](alchemical_comparison.svg). Each row shows genuine Idylwild original pixels, an adapted Cuspell-style SVG, and an unchanged existing Cuspell SVG for style reference. Right-hand G-series glyphs are not proposed replacements or meaning assignments.

**Runic:** R005, R008, R014, R017, R031, R044, R050, R062.

**Alchemical:** A011, A013, A017, A022, A026, A028, A030, A035.

The original Idylwild ZIP archives, license provenance and checksums remain preserved in `../../original/` and `../../README.md`. The canonical G001–G150 vectors, the official registry, and randomized rune-to-root assignment mechanism remain untouched.

### Optical notes for the subsequent selection phase

- A011 and A013 were spaced to avoid the crowded lower terminals previously seen in A050.
- R005 and R050 intentionally emphasize branching families; later compare with existing twig/asterisk style glyphs.
- R014 may be close to previous R015 and several existing Cuspell staff forms.
- R017 and R062 are intentionally simple but their distinctness among vertical symbols needs an audit.
- A022 resembles other ring-and-cross variants. A035 is relatively complex. Both require small-size and duplicate checks in Stage 2.

**Progress after this batch:** 80/299 external candidate designs stylized (40 Runic, 40 Alchemical), 219 remaining. There have been no KEEP / CHANGE / REPLACE / REMOVE decisions yet.
