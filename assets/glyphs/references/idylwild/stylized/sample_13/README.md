# Batch 13 · Idylwild Runic alternate-ink source designs

This batch adds **16 Runic source IDs (R118–R133)** as separate editable Cuspell-style SVGs. The raw Idylwild comparison shows these as alternate ink/rendering treatments of the shapes already covered by **R006–R021**. Rather than invent false distinctions, the 16 new SVGs intentionally reuse the corresponding visually approved contours. The separate SVGs and source references preserve one-to-one provenance for all source IDs.

**Important:** 16 *more source IDs processed* does **not** mean 16 more unique glyph shapes are available for the final pool. This runic variant family will be collapsed/assessed during Stage 2 alongside all mirrors and near-duplicates.
