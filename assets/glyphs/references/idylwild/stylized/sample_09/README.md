# Idylwild to Cuspell · Stylization batch 09

**16 candidate SVGs, none adopted.** The prior 128 were visually approved for style; this group includes eight Runic and eight Alchemical designs. View the three-column [Runic sheet](runic_comparison.svg) and [Alchemical sheet](alchemical_comparison.svg), or open the [local index page](index.html). Each row includes real original 16×16 pixels from the CC0 packs, a smooth editable Cuspell-style SVG, and one unchanged existing Cuspell reference glyph.

Runic IDs: R002, R030, R061, R063, R064, R065, R067, R068.

Alchemical IDs: A066, A067, A068, A069, A070, A071, A072, A073.

Visual styling uses 600×1000 em, 66-unit black strokes with rounded caps/joins. The new art is interpretive rather than a precise pixel outline. Original files and their hashes are in `../../original/` and `../../README.md`. Source artwork remains untouched, as does `assets/glyphs/recovery/source_geometry.json` and the 150 G-series SVGs.

Review considerations for later selection: R030 is merely an upright and likely redundant with R020; R065 has two bowls, so lower clearance and UI readability matter. A070's horizontal link has a wide silhouette; this is deliberately retained despite differing proportions. A068 and A073 add complex geometric silhouettes that should be small-size tested. These are **selection flags**, not decisions.

Progress: **144 of 299** Idylwild source IDs stylized (**72 Runic, 72 Alchemical**); **155** still to adapt. The user approved Batch 08 styling, but this batch awaits review. The final collection must contain at least 218 visually distinctive glyphs, potentially with many current Cuspell mirrors removed. No inventory decisions or root mappings have been made.
