# Cuspell meaning assignment — first visual review

**Draft only, awaiting user visual approval (2026-11-21).** The files here are proposals, not an update to canonical language semantics, the font's Unicode mappings, the 217 registered runes, or the 234 approved glyph designs.

- `draft_01.json`: first 18 beginner spellcraft signs from the stress-tested checkpoint-141 progression, plus proposed numeric-one `@` glyph, with registered lexicon IDs and original G/A/R source IDs.
- `review_01.svg`: self-contained labeled visual sheet from the existing approved source SVGs. No modifications to individual shapes.
- `../keyboard_kit/meaning_assignment_preview_01.html`: copy this file into the extracted keyboard kit alongside its TTF to see real-font examples at 20/32/34 px.

The proposal intentionally makes the most frequent spellcraft contrasts legible: `Move / This / There`, `Begin / End`, `This / You / Self`, `Whole / Locked / Magic`, and `Persist / Prevent`. `Begin` and `End` use distinguishable up/down-arrow relatives for a mnemonic opposition; if the mirrored relationship is too easy to misread, swap one during user review. `Light` uses the existing solar-form A015, `Persist` the infinity-like A018, `Prevent` the crossing G041; `@` proposes the simple circled-staff R039.

Do not promote to canonical assignment until the user explicitly approves or revises these choices. Later meaning assignments must use the remaining eligible 215 source IDs without duplicating those approved from this set.
