# Cuspell Compact PC test font

Install **CuspellCompact-Regular.ttf** (family **Cuspell Compact**) and open the included **meaning_keyboard.html** from the same folder. Type Cuspell, convert it to glyphs, and paste into an editor using Cuspell Compact. At 32–34 px, adjacent glyphs should be close like letters within a word. Try 20 px as a minimum and verify no overlapping/clipped contours.

All glyph drawings and U+E000–U+E0E9 assignments come from the untouched Cuspell 234 Review source. Only left/right spacing and the installable font family name change. The original review TTF/WOFF2/ZIP remain preserved.
