How to use this as an installable font

Install CuspellCodexReview-Regular.ttf from the same ZIP (double-click and choose Install on Windows/macOS; open in Fonts on Linux). Select Cuspell Codex Comparison in your document editor, then paste glyph text copied from the box above.

Characters use the Unicode Private Use Area: Cuspell U+E001–U+E096; Runic U+E100–U+E1DF; Alchemical U+E200–U+E24A. Other fonts will not display them correctly. The text file and clipboard retain codes, not ordinary letters. This kit is for comparison, not the final Cuspell assignment or player UI.
