# Cuspell 234 PC testing kit

1. Download and extract Cuspell_Codex_Keyboard_Kit.zip.
2. Install CuspellCodexReview-Regular.ttf. Select font family Cuspell 234 Review in your word processor.
3. Open keyboard.html from the extracted folder, click glyphs to type, and copy/paste the result. chart.html is the printable catalog.
4. Test at 32–34px or larger (minimum 20px). Report spacing or glyph problems before assigning meanings.

Contains exactly 234 source glyphs and 13 approved punctuation marks. Private use U+E000–U+E0E9 maps to G/A/R source glyph IDs in glyph_map.csv. Although all 217 rune meanings plus numeric `@` now have approved mappings in `language/core/glyph_assignments.json`, this preserved PC test font and keyboard still use their original nonsemantic selection/typing behavior. The separate name-to-glyph typing workflow has not been built.
