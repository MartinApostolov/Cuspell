# Cuspell — 234 surviving glyphs (PC test package)

**Current status, 2026-11-21:** The handwritten Cuspell glyph selection and exhaustive similarity review are complete. All thirteen punctuation shapes were approved. The approved test set is **234 unassigned magic/numeric design candidates** (94 native G + 140 stylized A/R). The 217 roots plus number-sign assignment will occur **only after testing on the user's PC**.

## Current installable font and typing page

**Download:** [Cuspell_Codex_Keyboard_Kit.zip](keyboard_kit/Cuspell_Codex_Keyboard_Kit.zip). Extract it, install **CuspellCodexReview-Regular.ttf** (font family **Cuspell 234 Review**), and open **[keyboard.html](keyboard_kit/keyboard.html)** in a browser, keeping the TTF in the same directory. Click symbols to type, then copy and paste them into a text editor using the installed font. The **[chart.html](keyboard_kit/chart.html)** page provides a printable chart; **[glyph_map.csv](keyboard_kit/glyph_map.csv)** maps every test codepoint to its original ID.

The test kit uses temporary private-use Unicode U+E000–U+E0E9 for the **234** glyph designs. These are purely test slots and **do not assign meanings**. The 13 approved punctuation glyphs are mapped to their ordinary Unicode characters. Use 32–34 px as the main target, with 20 px minimum.

The installer, typing webpage, printable chart, map, manifest, and a one-download ZIP are generated by `build_selected_review_font.py` and validated by the [font workflow](../../../../.github/workflows/cuspell-codex-comparison-font.yml). Generated files are committed back into `keyboard_kit/` after the workflow passes.

The **previous 449-glyph comparison package is superseded**. Its original builder is archived at `archive/glyphs/old_font_builders/build_unified_font_449.py`; previous ZIP/font versions remain available in Git history. Do not run the old comparison builder against current selection state.

## Rebuild and verification

`compare_codices.py` uses Pillow and CairoSVG; it reads both ZIPs and
`../../recovery/source_geometry.json` without changing any canonical
glyph source. Reproduce it with:

```sh
python -m pip install pillow cairosvg
python assets/glyphs/references/idylwild/compare_codices.py
PYTHONPATH=src python -m unittest discover -s tests -p "test_idylwild_reference_assets.py" -v
```

GitHub workflow `.github/workflows/idylwild-comparison.yml` downloads
the two public source ZIPs, **verifies them against the user-uploaded
checksums**, performs archive tests, renders both comparisons using
the full Cuspell registry, then commits the verified ZIPs and generated
images back to `main`. Upstream download, hash, validation, or rendering
failure aborts the job rather than committing misleading outputs.

asset packs include historical/alchemical motifs; CC0 concerns the
pack creators' artwork, not any exclusivity over an underlying motif.
