# Spellcraft Progression

_Status: full stress-tested learning path — checkpoint 141_

This file continues after `BEGINNER_SPELLCRAFT.md`.

The full staged path still reaches **29 semantic signs**, but checkpoint 141 no longer calls all 29 “beginner.”

The teaching boundaries are now:

- **Beginner spellcraft** — through 18 semantic signs;
- **Intermediate composition** — through 24;
- **Advanced spell programming** — through 29.

The 11-sign semantic core remains the first lesson inside the beginner course.

## Intermediate composition

Intermediate spellcraft begins after the learner already knows direct state change, measured attributes, creation, duration, and exact-event protection.

### Shared visual representation — 20 signs

Add:

`Vision Represent`

Examples:

`Begin Represent This You Vision!`

`End Represent This You Vision!`

`Persist Represent This You Vision ThisInterval!`

`Create i:Entity At $i There Begin Represent $i This Vision!`

`Represent` is an objective carrier/content/channel state.

It does not force any observer to perceive, believe, or understand the content, and it does not make the represented thing physically present or true.

This is the first intermediate module because it introduces a new ontology rather than merely another direct effect.

### Proposition/state conjunction — 21 signs

Add:

`And`

Example:

`Find Self This Whole This And Magic This!`

A Create profile can likewise contain a conjunction:

`Create i:Entity At $i There And Magic $i Begin Represent $i This Vision!`

At this level, `And` is taught in Proposition/StateProposition slots. Event-level transactional `And` remains advanced.

### Ordered and concurrent event composition — 23 signs

Add:

`Sequence Concurrent`

Ordered:

`Sequence Move This There Begin Magic This!`

Concurrent:

`Concurrent Move This There Begin Magic You!`

`Sequence` and `Concurrent` are general-purpose event composition.

The special continuation attached to `Create` is not a replacement for `Sequence`; it exists to keep one fresh binder in lexical scope.

### Finite repetition — 24 signs

Add:

`Repeat`

Example:

`Repeat @@@ Create x:Entity At $x There Change $x Light «LightUnit» @!`

This requests three distinct Create invocations.

`Repeat` is always finite when taught here. It does not imply an unbounded loop.

Checkpoint 141 places the **intermediate boundary here**, at 24 semantic signs.

## Advanced spell programming

The next stages introduce qualitatively heavier machinery: nested collection binders, persistent reactive watchers, and explicit relative temporal frames.

### Bounded multi-target distribution — 27 signs

Add:

`Collect Member Each`

Example:

`Each Collect x:Entity Member $x This y:Entity Begin Magic $y!`

Read it as:

1. resolve the Entity members of designated group `This`;
2. bind each resolved member as `y`;
3. instantiate `Begin Magic $y` once per member.

This is advanced because it combines selection, a typed collection binder, a second distribution binder, and repeated event instantiation.

`Collect` does not grant omniscient search. The active context must supply a resolvable domain/group membership relation.

### Reactive programming — 28 signs

Add:

`Trigger`

Example:

`Trigger Locked This End Locked This ThisInterval!`

This creates a one-shot finite-lifetime watcher.

The simple form does not export a hidden witness.

Bound-witness Trigger remains further advanced.

### Relative local time-flow — 29 signs

Add:

`TimeFlow`

Example:

`Persist TimeFlow You Self @@ ThisInterval!`

This maintains You's local physical/process temporal progression at factor 2 relative to Self over the designated interval.

The reference is explicit; there is no unnamed universal “normal time” frame.

Useful optional extensions are:

`Persist TimeFlow You Self Zero ThisInterval!`

for stopped local progression, and:

`Persist TimeFlow You Self Divide @ @@ ThisInterval!`

for factor 1/2.

`Zero` and `Divide` are not required by the 29-sign progression.

Region TimeFlow, nested temporal regions, boundary/crossing cases, and any future time-reversal semantics remain advanced extensions.

## Why these boundaries

The boundary is not based only on sign count.

Checkpoint 141 stress-tests the cumulative path by asking whether each stage introduces:

- only direct spell construction;
- general-purpose composition/control flow;
- nested binders or collection execution;
- persistent watcher semantics;
- a new metaphysical frame such as relative temporal progression.

That gives the current division:

- **Beginner (18):** direct construction and exact protection;
- **Intermediate (24):** representation and reusable composition;
- **Advanced (29):** collections, watchers, and time-flow.

The full progression is still cumulative. A learner can continue straight through it, but finishing all 29 signs is no longer required to be called a beginner.

Even after the 29-sign path, Cuspell still contains more advanced uses of already-known signs, including:

- event-level transactional `And`;
- mixed `And` / `Or` grouping and branch policy;

- general collection selectors such as filtering/ranking/random selection;

- Region TimeFlow and other advanced temporal realization cases.

The 50-sign SRD projection remains a coverage benchmark, not the next course level.
