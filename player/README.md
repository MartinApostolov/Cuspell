# Cuspell Player Reference

This folder is for **players and in-world users of Cuspell**. It intentionally leaves out parser internals, design history, reduction audits, rejected alternatives, and implementation notes.

Start with:

1. [BEGINNER_SPELLCRAFT.md](BEGINNER_SPELLCRAFT.md) — the 50-sign spell-first teaching subset and example magical Commands.
2. [QUICK_START.md](QUICK_START.md) — the minimum general grammar behind those spells.
3. [RULES.md](RULES.md) — the canonical player-facing writing rules.
4. [RUNES.md](RUNES.md) — the complete current rune/sign dictionary.
5. [names/OLD_NAMES.md](names/OLD_NAMES.md) — established historical vocabulary.
6. [ADVANCED_GRAMMAR.md](ADVANCED_GRAMMAR.md) — roles, binders, open questions, collections, and nested event groups.

The files under `docs/`, `language/`, and `world/` remain the maintainer/designer sources of truth. Player reference files must stay consistent with them and must not invent new semantics.
