# Cuspell Player Reference

This folder is for **players and in-world users of Cuspell**. It intentionally leaves out parser internals, design history, reduction audits, rejected alternatives, and implementation notes.

Start with:

1. [BEGINNER_SPELLCRAFT.md](BEGINNER_SPELLCRAFT.md) — the 11-sign first-lesson core and the full 18-sign beginner course.
2. [SPELLCRAFT_PROGRESSION.md](SPELLCRAFT_PROGRESSION.md) — the intermediate path through 24 signs and advanced extension through 29.
3. [SPELLCRAFT_COVERAGE.md](SPELLCRAFT_COVERAGE.md) — the retained 50-sign SRD-derived coverage projection.
4. [QUICK_START.md](QUICK_START.md) — the minimum general grammar behind those spells.
5. [RULES.md](RULES.md) — the canonical player-facing writing rules.
6. [RUNES.md](RUNES.md) — the complete illustrated rune/sign dictionary with all approved designs.
7. [names/OLD_NAMES.md](names/OLD_NAMES.md) — established historical vocabulary.
8. [ADVANCED_GRAMMAR.md](ADVANCED_GRAMMAR.md) — roles, binders, open questions, collections, and nested event groups.
9. [GLYPH_TYPING.md](GLYPH_TYPING.md) — how to type, display, copy, and reverse-convert approved rune writing.
10. [Meaning-aware keyboard](../assets/glyphs/references/idylwild/keyboard_kit/meaning_keyboard.html) — offline typing page, kept beside the original font.

The files under `docs/`, `language/`, and `world/` remain the maintainer/designer sources of truth. Player reference files must stay consistent with them and must not invent new semantics.
