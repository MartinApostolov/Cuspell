# Cuspell Player Reference

This folder is for **players and in-world users of Cuspell**. It intentionally leaves out parser internals, design history, reduction audits, rejected alternatives, and implementation notes.

Start with:

1. [BEGINNER_SPELLCRAFT.md](BEGINNER_SPELLCRAFT.md) — the current 11-sign semantic core plus small modules for Light, fresh creation, duration, exact-event protection, and shared visual representation.
2. [SPELLCRAFT_COVERAGE.md](SPELLCRAFT_COVERAGE.md) — the retained 50-sign SRD-derived coverage projection.
3. [QUICK_START.md](QUICK_START.md) — the minimum general grammar behind those spells.
4. [RULES.md](RULES.md) — the canonical player-facing writing rules.
5. [RUNES.md](RUNES.md) — the complete current rune/sign dictionary.
6. [names/OLD_NAMES.md](names/OLD_NAMES.md) — established historical vocabulary.
7. [ADVANCED_GRAMMAR.md](ADVANCED_GRAMMAR.md) — roles, binders, open questions, collections, and nested event groups.

The files under `docs/`, `language/`, and `world/` remain the maintainer/designer sources of truth. Player reference files must stay consistent with them and must not invent new semantics.
