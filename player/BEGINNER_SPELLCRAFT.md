# Beginner Spellcraft

_Status: stress-tested beginner boundary — checkpoint 141_

The **first lesson** is still the 11-sign semantic core.

The complete **beginner spellcraft course** now stops at **18 semantic signs**. Checkpoint 141 stress-tested the full 29-sign path and found that the later modules are valid, but they stop being beginner material once the course moves from direct spell construction into representation ontology and general-purpose programming.

The beginner course is therefore:

- 11-sign semantic core;
- +2 signs for measured Light change;
- +2 signs for fresh creation;
- +2 signs for finite maintenance;
- +1 sign for exact-event protection.

Nothing after `Prevent` is required to finish beginner spellcraft.

## 1. First six signs

`This There Move Begin End Whole`

Commands end in:

`!`

Examples:

`Move This There!`

`Begin Whole This!`

`End Whole This!`

This first step teaches only direct movement and Begin/End state transitions.

## 2. Add reusable target/state vocabulary

Add:

`You Locked Magic`

Cumulative semantic vocabulary: **9 signs**.

Examples:

`Move You There!`

`Begin Locked This!`

`End Locked This!`

`Begin Magic This!`

`End Magic This!`

The grammar does not change; the learner is reusing the same patterns with new state vocabulary.

## 3. Add bounded yes/no discovery

Add:

`Self Find`

Cumulative semantic vocabulary: **11 signs**.

Examples:

`Find Self This Whole This!`

`Find Self This Locked This!`

`Find Self This Magic This!`

The first `This` is the explicit information-access scope. The last `This` is the subject inside the queried proposition.

Open-query binders and broad search are later material.

## 4. The 11-sign semantic core

`Self This You There`

`Move Begin End Find`

`Whole Locked Magic`

This is the actual first-lesson vocabulary.

Every one of these signs appears in the starter spellbook, and this layer needs no binders, units, Old Names, collections, duration machinery, or general programming.

## 5. Beginner module 1 — measured Light change

Add:

`Change Light`

Cumulative semantic vocabulary: **13 signs**.

This module also teaches:

- `@` as the positive unit number 1;
- `«LightUnit»` as the established Light unit Old Name.

Example:

`Change This Light «LightUnit» @!`

This changes an already-existing Entity's Light output. It does not create a new object.

## 6. Beginner module 2 — fresh creation

Add:

`At Create`

Cumulative semantic vocabulary: **15 signs**.

This module introduces the first typed binder:

`:«This»`

and its reference:

`$«This»`

Example:

`Create :«This» At $«This» There Change $«This» Light «LightUnit» @!`

Meaning:

1. allocate one fresh Entity;
2. place it at the designated Location `There`;
3. keep the fresh identity in scope;
4. set its Light output.

The exact visible Form is not guessed by Cuspell. A world may deterministically realize this profile as a glowing orb, but that realization must come from world-generation rules rather than hidden language semantics.

## 7. Beginner module 3 — duration and active maintenance

Add:

`ThisInterval Persist`

Cumulative semantic vocabulary: **17 signs**.

`ThisInterval` must resolve to one objectively designated TimeInterval from the casting/context environment. It never silently means “some duration” or “forever.”

Examples:

`Persist Whole This ThisInterval!`

`Persist Locked This ThisInterval!`

`Persist Magic This ThisInterval!`

`Persist` actively maintains the written state over the interval. It is not another spelling of `Begin`.

## 8. Beginner module 4 — exact-event protection

Add:

`Prevent`

Cumulative semantic vocabulary: **18 signs**.

Beginner `Prevent` means:

`Prevent event interval!`

Examples:

`Prevent Move This There ThisInterval!`

`Prevent End Whole This ThisInterval!`

`Prevent Begin Locked This ThisInterval!`

This is exact protection. Preventing `End Whole This` does not secretly block every possible physical process that could make the object non-Whole.

Generic matcher/antimagic `Prevent` remains advanced.

## 9. Why beginner stops here

The next module, shared representation, is perfectly valid Cuspell—but it introduces a new ontology: a carrier can represent content through a channel without forcing perception, truth, solidity, or physical presence.

After that, the course moves into:

- proposition composition;
- ordered/concurrent event programs;
- repetition;
- collection binders and multi-target distribution;
- reactive watchers;
- relative temporal frames.

Those are no longer necessary for basic spell construction.

So checkpoint 141 draws the beginner boundary at **18 semantic signs**, while keeping the 11-sign core as the first lesson.
