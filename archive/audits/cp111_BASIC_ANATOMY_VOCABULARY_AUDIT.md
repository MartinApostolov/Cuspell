# Checkpoint 111 — Basic Anatomy Vocabulary Audit

_Status: first balanced civilization-vocabulary expansion batch_

## Purpose

Checkpoint 106 found that the historical vocabulary layer was visibly corpus-shaped:

- Wrist, Tendon, and Stomach existed;
- Head, Foot, Tooth, Nose, and other much more ordinary anatomy words did not.

Checkpoint 111 audits the first high-priority domain, **basic anatomy**, using the classification rules established by checkpoints 106–110.

The goal is not to translate an English anatomy dictionary. The goal is to identify the small set of anatomy concepts that ordinary pre-magic speakers would almost certainly lexicalize and determine whether they require:

1. composition only;
2. an Old Name;
3. a New Name category;
4. a semantic-language addition;
5. a world-model concept.

## Existing anatomy before this batch

The core already had historical vocabulary for:

- body;
- hand;
- eye;
- ear;
- mouth;
- skin;
- bone;
- flesh;
- blood;
- organ;
- stomach;
- wrist;
- tendon;
- wound;
- claw;
- tail.

This was enough to prove the world-concept/Old-Name architecture, but it was not a balanced ordinary vocabulary.

## Audit criteria

A basic anatomy concept is a strong Old Name candidate when it is:

- common across ordinary daily life;
- repeatedly discussed without specialist medicine;
- plausibly lexicalized long before magic;
- objectively classifiable by the world model;
- awkward or unnatural to rebuild compositionally every time;
- not an independently productive semantic operation.

The historical Sign does **not** need to be a perfect modern definition. It only needs a plausible etymology from vocabulary available at the time.

Exact anatomy belongs to the world concept/classifier.

## Accepted first-batch concepts

### Head

**Classification:** world Kind + Old Name.

Historical Sign:

`«Know«LifeMatter»Part»`

Historical cost: **4**.

Rationale:

The head is universally salient in ordinary speech. The old wording foregrounds the body part associated with knowing/thought. This is historical folk etymology, not a claim that cognition defines headhood.

### Face

**Classification:** world Kind + Old Name.

Historical Sign:

`«VisionSaySurface«Know«LifeMatter»Part»»`

Historical cost: **7**.

Rationale:

Face is socially and visually central and is not naturally replaced by repeatedly saying “the visible/communicative surface of the head.” The spelling builds on the newly established Head word.

### Arm

**Classification:** world Kind + Old Name.

Historical Sign:

`«ControlMove«LifeMatter»Part»`

Historical cost: **5**.

Rationale:

A common manipulative limb deserves its own word. Control + Move distinguishes the historical spelling from the pre-existing Hand word.

### Leg

**Classification:** world Kind + Old Name.

Historical Sign:

`«Move«LifeMatter»Part»`

Historical cost: **4**.

Rationale:

A primary locomotor limb is ordinary enough to lexicalize. Exact species applicability/homology remains world ontology.

### Foot

**Classification:** world Kind + Old Name.

Historical Sign:

`«MoveTouch«LifeMatter»Part»`

Historical cost: **5**.

Rationale:

The etymology foregrounds locomotion plus contact. It is not a formal definition of all possible feet.

### Finger

**Classification:** world Kind + Old Name.

Historical Sign:

`«ControlPart«Control«LifeMatter»Part»»`

Historical cost: **6**.

Rationale:

Finger is frequent and manipulation-relevant. The spelling explicitly grows later vocabulary from the already established Hand Old Name.

### Nose

**Classification:** world Kind + Old Name.

Historical Sign:

`«Olfaction«LifeMatter»Part»`

Historical cost: **4**.

Rationale:

This follows the same historical strategy already used by Eye and Ear: foreground the sensory channel associated with the part.

### Tooth

**Classification:** world Kind + Old Name.

Historical Sign:

`«HardEat«LifeMatter»Part»`

Historical cost: **5**.

Rationale:

Hardness and eating are salient pre-scientific features. Exact dental morphology belongs to the world classifier.

### Tongue

**Classification:** world Kind + Old Name.

Historical Sign:

`«SayEat«LifeMatter»Part»`

Historical cost: **5**.

Rationale:

Speech and eating are ordinary salient functions. Cuspell does not currently have a Taste channel, and checkpoint 111 does not add one merely to improve an etymology.

### Heart

**Classification:** world Kind + Old Name.

Historical Sign:

`«Move«LiquidLifeMatter»«Use«LifeMatter»Part»»`

Historical cost: **8**.

Rationale:

The later word reuses the earlier Blood and Organ Old Names and foregrounds blood movement. This is a historically plausible functional description without creating a circulation-specific semantic root.

### Brain

**Classification:** world Kind + Old Name.

Historical Sign:

`«Know«Use«LifeMatter»Part»»`

Historical cost: **5**.

Rationale:

Brain is a common organ concept. The historical wording foregrounds cognition/knowing while exact neurobiology remains world ontology.

### Hair

**Classification:** world Kind + Old Name.

Historical Sign:

`«ChangeExtentSurface«LifeMatter»Part»`

Historical cost: **6**.

Rationale:

The old wording foregrounds growing/changing-extent body-surface parts. It is intentionally non-exhaustive and does not live-classify every hair instance by current growth state.

## Why all twelve are world concepts

These nouns identify **Kinds of things**, not reusable logical/physical operations.

Cuspell already has enough semantic machinery to describe facts about them:

- Part;
- Surface;
- Form;
- Length/Extent;
- Move;
- Touch;
- Sense channels;
- Damage/Health/Pain/Ill;
- Whole/Joined;
- Blood/Body/Organ historical concepts.

Adding Head, Face, Arm, etc. as base semantic roots would therefore confuse **lexical frequency** with **semantic primitiveness**.

The world classifier supplies exact membership.

## Etymology is not live classification

This checkpoint relies heavily on the existing frozen-etymology rule.

Examples:

- an injured leg remains a Leg even if it cannot currently Move;
- a blind eye remains an Eye;
- a silent tongue remains a Tongue;
- a transplanted heart remains a Heart;
- cut hair remains Hair even when it is no longer growing;
- a head does not cease to be a Head if cognition is absent.

The historical name units explain why the word formed and determine mana cost. They do not define current membership.

## No new semantic gap found

None of the twelve candidates requires:

- a new root;
- a new constructor;
- a new type;
- a new frame;
- a grammar change.

This batch therefore strengthens the world-vocabulary layer without expanding the productive semantic basis.

## Deferred anatomy

Checkpoint 111 deliberately stops after the high-frequency basic set.

Potential later Old Name candidates include:

- neck;
- shoulder;
- elbow;
- knee;
- chest;
- back;
- abdomen/belly;
- muscle;
- joint;
- nail;
- lip;
- throat;
- lung;
- liver;
- kidney;
- intestine;
- genital/reproductive anatomy;
- finer bone/organ/tissue vocabulary.

These are **not rejected**. They are deferred until corpus/world pressure shows which distinctions are common enough to justify historical lexicalization.

This avoids turning the core Old Name registry into an arbitrary English anatomical thesaurus.

## New Name boundary

Individual anatomical structures do not normally need New Names.

New Names remain appropriate for:

- a uniquely named organ/artifact/body part in a setting;
- named medical procedures;
- named diseases;
- named anatomical Skills/System terms;
- culturally specific technical classifications.

The Yona package already demonstrates this with names such as Anatomical Analysis and Anatomical Blueprint.

## Result

The ordinary anatomy layer is now much less corpus-shaped.

The next balanced civilization domain is:

**natural geography and weather**.

That pass should use the same discipline: classify first, add only historically plausible common vocabulary, and treat any inability to express the underlying distinction as semantic pressure rather than papering it over with an Old Name.
