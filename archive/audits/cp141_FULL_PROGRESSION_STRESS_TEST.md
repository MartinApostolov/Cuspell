# Checkpoint 141 — Full Spellcraft Progression Stress Test

_Status: completed teaching-boundary audit_

## Trigger

Checkpoint 140 completed the planned 29-sign cumulative spellcraft path.

The remaining task was not to add more signs. It was to test whether the full path should actually be called beginner material, whether any module had hidden semantic prerequisites, and whether the module order still matched structural difficulty.

## Test 1 — hidden registered-sign prerequisites

Every required example is parsed and its registered semantic signs are compared against the cumulative vocabulary available at that stage.

Result:

**No hidden registered-sign prerequisite remains.**

Units, Old Names, binders, variables, and other notation still count as learner load, but no example secretly calls a semantic sign that has not yet been introduced.

## Test 2 — where beginner material actually stops

The first four follow-on modules after the 11-sign core are still direct spell construction:

1. measured Light change;
2. fresh creation;
3. finite active maintenance;
4. exact-event protection.

These reach **18 semantic signs**.

After that point the path changes character.

Shared representation introduces a carrier/content/channel ontology where the representation can be shared without forcing perception, truth, solidity, or physical presence.

The following modules introduce general proposition/event composition.

Therefore the stress test places the actual **beginner boundary at 18 signs**, after simple exact-event Prevent.

## Test 3 — intermediate composition boundary

The next four modules are:

1. `Vision Represent` -> 20;
2. `And` -> 21;
3. `Sequence Concurrent` -> 23;
4. `Repeat` -> 24.

These are composition-heavy but still avoid nested collection selection, persistent reactive watchers, and temporal-frame manipulation.

They therefore form **intermediate composition**, ending at **24 signs**.

## Test 4 — advanced boundary

The remaining three modules require qualitatively heavier execution models:

- reactive watcher state;
- nested selection/distribution binders and collection resolution;
- explicit relative temporal progression.

They therefore form the **advanced extension**, ending at **29 signs**.

## Test 5 — module ordering

Checkpoint 140's order placed bounded multi-target distribution before simple Trigger.

The stress test changes that order.

### Simple Trigger first

`Trigger Locked This End Locked This ThisInterval!`

This introduces one watcher model but reuses already-known:

- Proposition;
- EventSpec;
- ThisInterval;
- one-shot action semantics.

It adds no new binder syntax.

Cumulative semantic count becomes **25**.

### Multi-target distribution second

`Each Collect x:Entity Member $x This y:Entity Begin Magic $y!`

This requires:

- a selection binder;
- explicit membership;
- a resolved collection;
- a second distribution binder;
- repeated EventSpec instantiation.

It is structurally heavier than simple Trigger.

Cumulative semantic count becomes **28**.

### TimeFlow last

`Persist TimeFlow You Self @@ ThisInterval!`

TimeFlow is syntactically compact but conceptually changes the temporal frame of physical/process evolution, so it remains the final advanced stage at **29**.

## Final teaching boundaries

### First-lesson core — 11 signs

`Self This You There Move Begin End Find Whole Locked Magic`

### Beginner spellcraft — 18 signs

Adds:

`Change Light At Create ThisInterval Persist Prevent`

The beginner course ends here.

### Intermediate composition — 24 signs

Adds:

`Vision Represent And Sequence Concurrent Repeat`

### Advanced extension — 29 signs

Adds, in order:

`Trigger Collect Member Each TimeFlow`

The 50-sign SRD-derived subset remains a separate coverage benchmark rather than a course level.
