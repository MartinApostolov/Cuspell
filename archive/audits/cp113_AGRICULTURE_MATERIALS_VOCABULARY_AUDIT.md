# Checkpoint 113 — Food, Agriculture, and Common Materials Vocabulary Audit

_Status: third balanced civilization-vocabulary expansion batch_

## Purpose

Checkpoint 106 identified food/agriculture and common materials as another uneven domain. Existing Cuspell already had Food, Farm, Farmer, Fisher, Food Store, Water, Stone, Wood, Metal, Soil, Sand, Clothing, Spoon, and general Matter/phase/change/transfer semantics, but common plant products and everyday craft materials were still sparse.

Checkpoint 113 audits the next balanced domain without assuming every English food/material noun belongs in universal core vocabulary.

## Classification result

The batch accepts fourteen concepts as **world Kinds + Old Names**:

1. field;
2. seed;
3. leaf;
4. fruit;
5. crop/cultivated plant;
6. grain;
7. milk;
8. egg;
9. salt;
10. clay;
11. cloth/textile;
12. leather/hide;
13. glass;
14. fuel.

No candidate requires a new semantic root/type/frame.

## Farm modeling cleanup

Checkpoint 106 noted that Farm was described as a “place or establishment,” mixing different ontological readings.

Checkpoint 113 tightens Farm to a **persistent agricultural Entity/holding or cultivation site**.

Its:

- Fields;
- buildings;
- workers;
- ownership;
- organization/group facts;

are modeled separately.

This keeps Farm usable as a stable named/classified Entity without forcing one concept to alternate between place, event, and organization semantics.

The historical Farm Old Name remains unchanged in Sign/cost; only the classifier description is tightened.

## Why no universal StapleFood Kind

The earlier audit listed “bread or equivalent staple.”

Checkpoint 113 concludes that **staple** is relational to:

- a community;
- an ecology;
- an era;
- diet and food availability.

Therefore universal core should not contain a context-free StapleFood Kind.

Bread, rice, porridge, maize preparations, tubers, fantasy staple foods, etc. belong in the relevant world/history package and may receive Old Names there if historically established.

This is a world-model distinction, not a missing rune.

## Specific species and recipes

The same rule applies to:

- named cereal/crop species;
- flour;
- bread;
- cooking oils;
- spices;
- alcohol/beverages;
- cheeses;
- prepared dishes;
- recipes;
- culturally specific fibers/material grades.

These should not be preloaded into generic core unless later world/corpus evidence justifies them.

## No hidden process semantics

This batch does not add Grow, Sow, Harvest, Cook, Mill, Weave, Tan, Fire/Smelt, Ferment, or similar process roots.

Some production actions can already be described by existing state/change/transfer/use machinery; others preserve genuine manner/process distinctions and should be audited when needed.

Old Name nouns must not be used to claim those processes are already formally solved.
