# Yona four-chapter rerun — 274-test checkpoint

_Status: 2026-09-28 full semantic rerun against current executable Cuspell_

Sources re-read:

- Chapter 1, "Quite the Mystery"
- Chapter 2, "A Little Adventure"
- Chapter 14, "External Mana Manipulation"
- Chapter 47, "How Mana Works"

This pass was performed after closing the fourteen-item 2026 gap ledger, quantity value domains, ordered Sequence/First/Last, causation/information relations, objective space/time forms, and the older Chapter 1 discourse refinements.

The test for this pass is **manual semantic translatability**, not automatic English parsing. A feature counts as a language gap only if the source meaning cannot be preserved by a reasonable Cuspell expansion. Missing setting nouns/verbs are recorded separately as lexicon/world-package work.

## Result

The previous gap closure holds up well. No new top-level semantic category or type-system redesign is exposed by these four chapters.

Three genuine structural gaps remain.

### R1 — embedded question/directive content

**Status: real translation gap.**

Current Cuspell can:

- make a top-level yes/no or open question;
- represent Say/Assert/Claim/Promise;
- preserve exact quoted Signs;
- attach utterance-context metadata.

But it still cannot construct a first-class semantic **QuestionContent** or directive/command-content value *inside* another EventSpec and then say that a character asked/uttered it.

This matters repeatedly:

- Chapter 1: a character asks the narrator where she is going; System dialogue contains questions/directives.
- Chapter 2: orders, questions, and incomplete directive speech.
- Chapter 47: many teaching questions and answers.

A quoted Sign preserves the wording but not the semantic interrogative/directive force. Explicitly rewriting the character's Self/You references can preserve referents, but it does not solve the missing embedded speech-act content.

Needed executable layer:

- a constructor for yes/no QuestionContent;
- a constructor for open QuestionContent with typed binder(s);
- Ask(speaker, question-content, addressee/context?) -> EventSpec;
- a directive/command-content Information constructor usable by Say/Tell/Order-like speech acts.

### R2 — Almost over an EventSpec

**Status: real ordinary-language gap.**

Current Almost applies to a gradable PropertyDescriptor, which handles examples such as "almost tired" when Tired is a gradable property.

The audited chapters also use **near occurrence of an event**:

- nearly falling;
- nearly losing balance;
- almost accidentally causing an explosion.

This is not ApproxEqual and not a property threshold.

Needed ordinary-language semantics:

Almost(EventSpec) -> contextual Proposition

with the intended reading that the event did not fully occur but the situation approached the event's occurrence/completion boundary under the discourse standard. It must remain contextual and must not become a magical instruction or hidden nondeterministic threshold.

### R3 — permission authority/context

**Status: real frame gap.**

The written discourse specification defines:

Permitted(entity, EventSpec, authority/context) -> Proposition

but the executable frame currently records only agent + event.

Chapter 47 contains an explicit distinction between an action occurring and the narrator **not having granted permission** for it.

The authority/context role must therefore be executable. Granting/revoking permission can then be represented through the permission state/social model rather than being silently attributed to a global standard.

## Not blockers after re-evaluation

### Only / exclusivity

The rune inventory still lists Only as a scope/restriction operator and the chapters use English "only" frequently.

However the audited meanings are already expressible, though often longer:

- "the only sword I have seen" -> Unique over the visible/seen Sword collection;
- "the only plan available" -> Unique over the available Plan collection;
- "only use constructs" -> explicit restriction/negation over alternative allowed methods;
- "only knows about the System" -> quantified/filtered knowledge restriction.

Therefore Only remains desirable compression, but it is **not currently a semantic completeness blocker**. Its exact generic scope rules should not be invented merely to shorten these cases.

### Nested Self/You in direct quotations

Speech-act AST nodes now preserve which roles establish an utterance context, but the parser does not automatically reparse an embedded semantic quotation with Self/You rebound to that speaker/addressee.

For manual translation this is not blocking: the content can name the intended entities explicitly. It remains a convenience/spec-completeness issue rather than a failure to express the source meaning.

### Analogy/metaphor

Chapter 47 uses teaching analogies and figurative descriptions. Their propositional lesson/explanation can be represented with Explanation/Explains and explicit source/target facts. A first-class Analogy relation would preserve rhetoric more directly, but the current passages do not require it to preserve the core semantic content.

## Chapter 47 rerun

The detailed foreign-magic explanation continues to fit the architecture:

- mana properties can be scalar AttributeDescriptors;
- comparative strengths use OrderedValue/Quantity comparisons;
- potency change with fixed total mana uses Change + Preserve;
- stability/volatility behavior uses Stable/ChangeRate/trend semantics;
- damage proportions can use Ratio in a world Damage profile;
- formal prohibition uses Permitted/Not;
- recommendation uses Should;
- rumor/source attribution uses speech/epistemic structure;
- affinity restrictions use Can/Requires/Not;
- strongest-at-level uses collection extrema over a declared scalar;
- progression odds use probability/confidence and ordered evaluation;
- limited lifetime/range uses Duration/Distance/If;
- control threshold uses Almost/ordered capability measures;
- advice to use constructs uses Should/Habitual;
- telepathic communication is a medium/world-vocabulary specialization of information transfer;
- resource recovery/reabsorption uses Transfer/Distribution.

This chapter exposes:

- R2 in near-event language;
- R3 in explicit permission authority;
- R1 repeatedly in narrated questions.

"Only" is frequent but remains expandable rather than structurally necessary.

## Current conclusion

After re-reading all four chapters against the 274-test language, the known structural translation gap set is now:

1. embedded semantic question/directive content;
2. Almost(EventSpec);
3. explicit authority/context in Permitted.

Everything else encountered in these chapters is either:

- already expressible in current Cuspell;
- a verbose but valid composition;
- ordinary/world-specific vocabulary/ontology;
- or a stylistic/pragmatic distinction that does not block preservation of the core source meaning.

The next implementation batch should close R1-R3, then rerun these four chapters once more before moving on to new chapters.
