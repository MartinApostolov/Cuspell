# Yona four-chapter rerun — 291-test checkpoint

_Status: 2026-09-28 post-fix semantic rerun against current executable Cuspell_

Sources re-read:

- Chapter 1, "Quite the Mystery"
- Chapter 2, "A Little Adventure"
- Chapter 14, "External Mana Manipulation"
- Chapter 47, "How Mana Works"

This pass follows the 274-test rerun and the implementation of its residual gaps:

- embedded semantic QuestionContent / CommandContent with Ask and Tell;
- contextual Almost(EventSpec);
- explicit authority/context on Permitted;
- KnowAnswer / AnswerFor for unknown open-question answers.

## Result

**No remaining structural translation gap was found in these four chapters.**

This means the chapter meanings can now be represented compositionally in current Cuspell, assuming the ordinary/world-specific vocabulary needed for the entities, actions, Skills, anatomy, materials, social roles, and setting concepts is available.

This is not a claim that every English sentence has a one-to-one short Cuspell rendering. Some meanings remain verbose, and some convenient compression roots are still absent.

## Chapter 1

Previously difficult structures now have direct or compositional representation:

- narrated yes/no and open questions can be embedded as QuestionContent and used by Ask;
- System directives can be represented as CommandContent without becoming active commands;
- unknown methods can be represented as Not KnowAnswer over an open QuestionContent;
- Almost handles both gradable properties and EventSpecs;
- naming, anaphoric references, contrast, next occurrence, rate trends, recommendation, epistemic evidence, and prerequisites are executable.

Remaining Chapter 1 work is vocabulary/world ontology: food, occupations, social roles, emotions, household objects/states, System/Quest concepts, and ordinary action verbs.

## Chapter 2

The chapter's structural pressure is now covered:

- search-party pairs use Partition;
- priority/evaluation uses OrderedValue;
- orders use embedded Directive content;
- narrated questions use QuestionContent/Ask;
- near-fall language uses Almost(EventSpec);
- unknown displayed level uses UnknownValueOf / UnavailableValueOf;
- names and cross-chapter referents have explicit contextual forms.

Remaining work is maritime, anatomy, injury, monster, weapon, and ordinary-action vocabulary.

## Chapter 14

The mana-manipulation chapter is structurally covered by:

- QuestionContent and KnowAnswer for unknown methods/questions;
- DistributionOf / LocalDensity / TotalAmount / Redistribute;
- Transfer;
- Change + Preserve + BeforeValue;
- dimensional arithmetic and ApproxEqual;
- ShapeLike versus Kind identity;
- Touch versus Joined;
- Control;
- Rate/trend/frequency semantics;
- sense/perception families.

Remaining work is Yona-specific world data: mana/Skill/Class/Proficiency concepts, anatomy, construct-part vocabulary, and named abilities.

## Chapter 47

The foreign mana-system explanation is structurally covered by:

- embedded questions and narrated teaching dialogue;
- scalar AttributeDescriptors and ordered comparisons;
- Change + Preserve for potency with fixed mana amount;
- Stable / ChangeRate / Increasing / Decreasing for mana behavior;
- Ratio for proportional damage descriptions;
- Should and Permitted for recommendation versus permission;
- explicit authority on Permitted for "I did not give them permission";
- Almost(EventSpec) for near explosion/fall;
- Transfer/Distribution for resource movement;
- QuestionContent/KnowAnswer for knowledge gaps.

Remaining work is world vocabulary for Skills, Classes, Affinities, mana properties, spell categories, and ordinary actions.

## Non-blocking compression/convenience gaps

These are still useful future additions but did not prevent translation of the audited passages:

- generic Only scope restriction;
- compact Few / almost-everyone style quantifiers where explicit Count/Most constructions are longer;
- automatic English-like pronoun resolution (manual Cuspell translation can use explicit contextual references);
- a dedicated Analogy relation for preserving rhetoric rather than core propositional meaning;
- compact Attempt/Try lexicalization for failed/incomplete action attempts.

## Conclusion

For Chapters 1, 2, 14, and 47, the current language has reached **structural translation completeness** under the project's manual-translation goal.

The next meaningful test is fresh corpus pressure, not speculative grammar expansion:

1. continue sequentially with Chapter 3;
2. add another dialogue/social-heavy chapter;
3. add another body/evolution-heavy chapter;
4. treat new ordinary nouns/verbs as lexicon/world work unless they reveal a reusable semantic construction that cannot be expressed compositionally.

## 2026-09-28 correction from full v0.7 rerun

The item above describing Attempt/Try as merely non-blocking compression is superseded by the fresh full-source Chapters 1–14 + 47 rerun.

That rerun showed that `Intend` cannot preserve the truth condition that a real effort episode occurred, while directly asserting the goal incorrectly asserts success.

`Attempt(agent, goal) -> EventSpec` is therefore now a registered semantic molecule. See `CH01_14_47_V07_FULL_RERUN.md` and `CURRENT_GAPS_2026.md`.

The rest of this historical 291-test checkpoint remains preserved as written.
